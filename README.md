# What is CCL?
<img src="./logoCCL.jpeg" width="200" height="200">

Compact Class Language (CCL) is a passion project aimed to simplify writing Java classes through shorthand notation.
Started in December 2025 as a simple class writing program in C++, it’s evolving to deal with more, in less time.

## CCL Attribute notation
`[access][type]:[name]`

This is the structure of the **Attribute Notation** of CCL.  
It is divided into three parts, just as regular Java attributes.  
Attributes in CCL are written as one single string of text.

### $\color{Red}{\textsf{Access Shorthand Notation}}$
- public: $\color{Red}{\textsf{+}}$
- private: $\color{Red}{\textsf{-}}$
- protected: $\color{Red}{\textsf{\\#}}$

### $\color{blue}{\textsf{Type Shorthand Notation}}$
- byte: $\color{blue}{\textsf{y}}$ *(not integrated yet)*
- short: $\color{blue}{\textsf{s}}$ *(not integrated yet)*
- integer: $\color{blue}{\textsf{i}}$
- long: $\color{blue}{\textsf{l}}$ *(not integrated yet)*
- float: $\color{blue}{\textsf{f}}$
- double: $\color{blue}{\textsf{d}}$
- boolean: $\color{blue}{\textsf{b}}$
- char: $\color{blue}{\textsf{c}}$
- String: $\color{blue}{\textsf{S}}$
- ArrayList<type>: $\color{blue}{\textsf{AL.type}}$
To create an attribute with any other class, just type its name.
